# Multithreaded-TCP-Packet-Sniffer-and-TCP-Header-Analyzer
Information travels around devices in the form of data packets. Initial, packet sniffing tools were single threaded that might cause a "traffic jam" while reading,parsing and analyzing these packets in a single thread.  The main goal of this project is to develop a network packet sniffing system that can capture, monitor, and analyze TCP network traffic in real time efficiently using multi-threading and decoupled approach. The project aims to provide an understanding of how data travels through a network and identify important information such as source and destination IP addresses, sequence number, acknowledgement number,flags, port numbers, and packet size from the TCP headers. The initial process is to study the fundamentals of computer networks, packets, protocols, and packet sniffing, followed by identifying the required programming language, tools, and libraries. The next step is to design the basic structure and workflow of the system that will capture these data packets in its raw form. In addition to this ,all essential information is to be extracted from the tcp headers and then it can be stored in a ".cap" or a log file for future use and while storing this information in the file , we can use the concept of sorting and filtering of data based on the criteria set by the user.
